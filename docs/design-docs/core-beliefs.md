# Core Beliefs — 김프 차익거래 핵심 신념

> Created: 2026-04-06
> Status: ✅ Confirmed

---

## 시장 신념

### 1. 김프는 구조적 비효율이다
한국의 자본 이동 규제(외국환거래법)로 인해 KRW 기반 거래소와 USD 기반 거래소 간 가격 차이가 발생한다. 이 차이는 일시적이 아니라 **규제에 의해 구조적으로 유지**된다.

### 2. 김프는 회귀한다
김프는 특정 범위 내에서 진동한다. 극단적으로 벌어지면 차익거래자에 의해 줄어들고, 과도하게 좁혀지면 수요 압력으로 다시 벌어진다. 이 **평균회귀 성질**이 차익거래의 근거이다.

### 3. 방향성은 알 수 없다
BTC가 오를지 내릴지는 예측할 수 없다. 따라서 가격 방향에 베팅하지 않고, **현물 롱 + 선물 숏으로 방향성을 상쇄**한 뒤 김프 차이만 추출한다.

## 전략 신념

### 4. 다중 필터는 단일 지표보다 생존율이 높다
하나의 진입 조건만으로는 노이즈를 걸러내기 어렵다. **독립적인 7개 필터**를 순차 적용하면 저품질 진입을 구조적으로 차단한다.

### 5. RSI GAP은 김프 전용 시그널이다
같은 자산의 Upbit RSI와 Binance RSI 차이(RSI GAP)는 한국 시장의 과열/냉각을 감지한다.
- RSI GAP > 0: Upbit 과열 → 김프 확대 가능 → 진입 유리
- RSI GAP < 0: Upbit 냉각 → 김프 축소 가능 → 진입 불리

### 6. Trailing Stop은 타이밍 보정 도구이다
정확한 바닥/꼭지를 잡을 수 없다. 대신 **반전이 확인된 후 진입/청산**하는 Trailing Stop이 실용적이다.
- 진입: 김프가 저점을 찍고 반등할 때
- 청산: 김프가 고점을 찍고 하락할 때

### 7. 슬리피지는 전략의 적이다
Per-Trade 순수익이 0.25-0.3%인 전략에서 슬리피지 0.1%는 수익의 30-40%를 잠식한다. **사전 VWAP 추정 없이 진입하지 않는다.**

## 운영 신념

### 8. 무인 운영이 기본이다
1인 개발자가 24/7 모니터링할 수 없다. 봇은 **수동 개입 없이 안전하게 동작**해야 하며, 예외 상황에서는 포지션을 잡지 않는 것이 낫다.

### 9. 안정성이 수익성보다 우선한다
WebSocket 끊김 상태에서 주문을 넣어 한쪽만 체결되는 것은 수익 기회 상실보다 위험하다. **연결 확인 → 주문 실행** 순서를 반드시 지킨다.

### 10. 측정 없이 최적화하지 않는다
"이 파라미터를 바꾸면 좋아질 것 같다"는 가설이지 근거가 아니다. **백테스트 또는 시뮬레이션 데이터 없이 파라미터를 변경하지 않는다.**

## 에이전트 원칙

### A1. 코드 변경 전 측정 기준을 먼저 정한다
"무엇을 개선할 것인가"보다 "어떻게 개선을 측정할 것인가"를 먼저 답한다.

### A2. 파라미터 변경은 이전 값과 변경 이유를 기록한다
암묵적 변경은 허용하지 않는다. 커밋 메시지에 `[param] KEY: old → new (reason)` 형식으로 명시한다.

### A3. 주문 로직은 시뮬레이션에서 먼저 검증한다
라이브 코드(삼중 따옴표 블록)를 바로 수정하지 않는다. 시뮬레이션 모드에서 동작을 확인한 후 라이브에 반영한다.
